# LumaBridge

Трей-утилита для быстрого переключения драйверов лазерных плат **BJJCZ**
(`USB\VID_9588`, PID `9980 / 9899 / 9990 / 9999`) между двумя режимами:

- **EzCAD2** — штатный драйвер `Lmcv2u.sys` (Beijing JCZ);
- **LightBurn** — `WinUSB` (то, что обычно ставят через Zadig).

Zadig больше не нужен: переключение делается штатными средствами Windows
(`UpdateDriverForPlugAndPlayDevices` + перезапуск устройства), драйверы
зашиты внутрь exe.

## Использование

1. Запустить `LumaBridge.exe` (запросит права администратора).
2. В трее появится монограмма LUMINOGRAPH с точкой режима:
   - оранжевая точка — режим EzCAD2;
   - графитовая точка — режим LightBurn;
   - без точки — плата не найдена;
   - серая точка — режим не определён / идёт переключение.
3. **Левый клик** по иконке — брендированная панель со статусом, кнопками
   переключения и ссылкой luminograph.ru.
4. **Правый клик** — контекстное меню: «Режим EzCAD2» / «Режим LightBurn» /
   «Обновить статус» / «luminograph.ru» / «Выход».

Оформление — по бренд-гайду LUMINOGRAPH: оранжевый `#E75823`, графит `#202124`,
светлые панели `#F3F4F6`, шрифт MiSans (если установлен, иначе Segoe UI).

## Конвертация макетов .ezd → .lbrn2

Пункт меню «Макет .ezd → LightBurn…» (и кнопка в панели): выбираете файл
EzCAD2 — рядом появляется проект LightBurn с геометрией и параметрами
маркировки (мощность, скорость, частота, проходы, задержки, штриховки),
драйвер переключается на LightBurn автоматически, файл открывается.

- Парсер `.ezd` портирован с открытого проекта meerk40t (MIT).
- Поддерживаются: кривые (линии/Безье), прямоугольники, круги, эллипсы,
  полигоны, группы, штриховки (угол/шаг/кросс → слой Scan/Scan+Cut).
- Пока не переносятся: текстовые объекты и растровые картинки (считаются
  и показываются в отчёте), скругления углов прямоугольников.
- Координаты: центр EzCAD → центр поля 110×110 мм в LightBurn.

CLI-режим для автоматизации:

```
LumaBridge.exe --convert input.ezd output.lbrn2 [report.txt]
```

Всё необходимое (драйвер EzCAD2, подписанный пакет WinUSB, сертификат)
находится внутри exe, внешних файлов не требуется.

## Как это работает

- Плата определяется по Hardware ID через SetupAPI, текущий режим — по имени
  сервиса устройства (`Lmcv2u`/`LMCUSB` → EzCAD2, `WinUSB` → LightBurn).
- Пакет WinUSB (`drivers/winusb/BJJCZ_WinUSB.inf` + подписанный каталог)
  использует in-box драйвер Microsoft WinUSB (`Include=winusb.inf`).
- Каталог WinUSB подписан самоподписанным сертификатом LumaBridge (выпущен с именем `DriverSwitcher`);
  при первом переключении в режим LightBurn сертификат добавляется в
  LocalMachine\Root и LocalMachine\TrustedPublisher (модель Zadig/libwdi),
  поэтому установка проходит без предупреждений.

## Сборка

Требуется .NET 8 SDK:

```powershell
dotnet publish src\LumaBridge -c Release -r win-x64 --self-contained `
    -p:PublishSingleFile=true -o publish
```

Пересборка подписанного каталога WinUSB (нужен закрытый ключ PFX):

```powershell
scripts\New-SigningCert.ps1      # один раз: создать сертификат и PFX
scripts\Build-WinUsbPackage.ps1  # makecat + signtool -> drivers\winusb\BJJCZ_WinUSB.cat
```
